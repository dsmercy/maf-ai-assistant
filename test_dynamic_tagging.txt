## Test: Dynamic Instruction Tagging Flow
##
## Upload file → LLM detects tags → saved to Qdrant + PostgreSQL
## Chat query  → tag vocabulary fetched → Qdrant filtered search using dynamic tags
##
## Expected timing per query (cache warm):
##   Tag vocabulary fetch (cache hit) :   ~0ms
##   Query embed                       :  ~50ms
##   Cosine similarity match           :   ~5ms
##   Qdrant filtered search            :  ~20ms
##   LLM response generation           : 3–15s

# ─────────────────────────────────────────────────────────────
# Step 1 — Start the API
# ─────────────────────────────────────────────────────────────
# Run AssistantApi. Confirm these startup log lines appear:
#   [INF] Executed DbCommand ... SELECT "MigrationId"   <- migrations applied/skipped
#   [INF] IngestionWorker started
#
# Verify Qdrant collections exist (created automatically on startup if missing):
curl http://localhost:6333/collections


# ─────────────────────────────────────────────────────────────
# Step 2 — Clear existing instruction data (fresh test)

docker exec postgres psql -U assistant -d assistant_db_dev -c "DELETE FROM \"FileHashes\" WHERE \"RepositoryId\" = '00000000-0000-0000-0000-000000000000';"
docker exec postgres psql -U assistant -d assistant_db_dev -c "DELETE FROM \"IngestionJobs\";"

# Delete and recreate the instruction-embeddings Qdrant collection (removes old vectors)
curl -s -X DELETE http://localhost:6333/collections/instruction-embeddings

# Recreate manually (or restart the API to auto-create via EnsureQdrantCollectionAsync):
curl -s -X PUT http://localhost:6333/collections/instruction-embeddings \
  -H "Content-Type: application/json" \
  -d "{\"vectors\": {\"size\": 768, \"distance\": \"Cosine\"}}"


# ─────────────────────────────────────────────────────────────
