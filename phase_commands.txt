## Phase 1 — Commands to run manually
Step 1 — Edit secrets in .env
Open .env and replace these two values before proceeding:

JWT_SECRET → any random 32+ character string
WEBUI_SECRET_KEY → any random secret key

Step 2 — Verify tool installations
docker --version
docker compose version
git --version
dotnet --version

Step 3 — Create named volumes

docker volume create ollama-models
docker volume create qdrant-data
docker volume create postgres-data
docker volume create openwebui-data
docker volume create repository-cache

Step 4 — Create Docker network
docker network create ai-assistant-net

Step 5 — Start all containers
docker compose up -d

Wait ~30 seconds, then check status:

docker compose ps

Step 6 — Pull Ollama models
docker exec ollama ollama pull nomic-embed-text

Then the large coding model (~18 GB, 10-30 min):

docker exec ollama ollama pull qwen3-coder:30b

Verify:
docker exec ollama ollama list

Step 7 — Verify all services
curl http://localhost:6333/healthz
curl http://localhost:11434/api/tags
docker exec -it postgres psql -U assistant -d assistant_db -c "SELECT version();"

##Build the custom models in Ollama

docker exec ollama ollama pull qwen3-coder:14b

# Copy Modelfiles into the Ollama container
docker cp ollama/Modelfile.14b ollama:/tmp/Modelfile.14b
docker cp ollama/Modelfile.30b ollama:/tmp/Modelfile.30b

# Build custom models (named with -instruct suffix to distinguish from base)
docker exec ollama ollama create assistant-14b -f /tmp/Modelfile.14b
docker exec ollama ollama create assistant-30b -f /tmp/Modelfile.30b
Step 3 — Update config to use the custom models

appsettings.Development.json:


"Assistant": {
  "ChatModel": "assistant-14b"
}
appsettings.json (Docker/production):


"Assistant": {
  "ChatModel": "assistant-30b"
}
